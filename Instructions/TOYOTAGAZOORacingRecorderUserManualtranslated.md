## Specifications, Precautions, and Disclaimers

### 1. Outputted Driving Data

The TOYOTA GAZOO Racing Recorder records circuit driving data and outputs it to the Vitz GRMN-exclusive T-Connect Navigation system. Depending on GNSS reception, vehicle conditions, and the surrounding environment at the time of recording, the outputted data may differ from the actual driving data.

## About the TOYOTA GAZOO Racing Recorder

### 1. Overview

The TOYOTA GAZOO Racing Recorder transmits real-time vehicle data (vehicle speed, engine RPM, steering angle, etc.) and positioning data (GNSS) to the Vitz GRMN-exclusive T-Connect Navigation system. Additionally, it can record data compliant with the "Vehicle Data Visualizer" format directly to an SD memory card.

### 2. Workflow Setup

- Displaying on Navigation Screen: Refer to Section 1 (Page 14) and your T-Connect Navigation Manual.
- Recording to SD Memory Card: Refer to Section 3 (Page 16).
- Bluetooth® Communications: Refer to Section 4 (Page 19).

### System Requirements & Prerequisites

#### Required SD Memory Card

- Supported Specs: Standard SD (up to 2 GB), SDHC (up to 32 GB)
- File System: FAT32 or FAT16
- Verified Models:
  - Transcend TS2GSDC (2 GB)
  - TOSHIBA SD-L016G4 (16 GB)
  - SanDisk SDSDB-016G-J35U (16 GB)
- Note: Do not use miniSD or microSD conversion adapters, as data may become corrupt. Data consumption is approximately 20 MB per hour.

#### Supported Mobile Devices (Smartphones)

- Android: OS 4.0 or newer (Profile: SPP)
- iOS: iPhone 6 or newer (Profile: iAP2)
- Bluetooth Version: Ver 3.0 or higher

## Component Names and Functions

- GNSS Antenna: Receives satellite positioning signals (GPS/GNSS).
- Recorder Unit (Main Unit): Features the SD Card Slot and Main Unit LED.
- Switch Unit: Mounted separately; houses the Status LED, Switch LED, Mode Selection Slider, and START/STOP Button.

## Indicator Light Patterns

### 1. Main Unit LED (Red)

- Off: Power is OFF, or an error has occurred.
- Solid On: Power is ON.

### 2. Switch LED (Text Backlight)

- Off: Power is OFF, or an error has occurred.
- Solid On: Power is ON.
- Blinking: Bluetooth® pairing mode is active (blinks simultaneously with the Status LED).

### 3. Status LED (Red)

- Off: SD card standby mode or no card inserted.
- Solid On: Actively recording driving data to the SD card.
- Blinking (1-second intervals): GNSS satellite link dropped during active SD recording.
- Simultaneous Blinking: Bluetooth® pairing mode is active.

## How to Use

### 1. Displaying Data on T-Connect Navigation

1. Start the engine.
2. Verify that both the Main Unit LED and Switch LED are illuminated.
3. Check the vehicle data screen on the navigation system.

> Note: You do not need to insert an SD card or push any buttons if you are only viewing live navigation telemetry.

### 2. Switch Settings and Operations

#### Mode Selection Slider Modes

- AUTO: Automatically starts and stops recording based on your vehicle speed. (Bluetooth: Connected / Pairing: Disabled)
- MANU: Manually manage recording via the START/STOP button. (Bluetooth: Connected / Pairing: Disabled)
- OFF: Disables telemetry recording features. Used to configure Bluetooth® device pairing.

#### START/STOP Button Operations

- Short Press (in AUTO/MANU): Manually triggers a recording start or stop.
- Long Press (3+ seconds in OFF): Launches Bluetooth® pairing mode.

### 3. Recording to an SD Memory Card

1. Insert a compatible SD card and lock the slot cover securely.
2. Start the engine and confirm both LEDs light up.
3. Select your recording mode:

#### AUTO Mode Functionality

- Automatic Start: Triggers when vehicle speed reaches 1 km/h or higher.
- Automatic Stop: Triggers when the vehicle is completely stopped for 2 continuous minutes.

> Note: Pressing START/STOP while driving over 1 km/h will split the log into a new file.

#### MANU Mode Functionality

- Press the START/STOP button to manually open and close data logs.

#### Driving Data File Specifications

- File Name Format: YYYYMMDDHHMMSS.vdv based on the exact start time in Coordinated Universal Time (UTC). (Japan Standard Time is UTC + 9 hours)
- File Directory: Created directly in the root directory of the SD card.
- Maximum Duration: Single files cap out at a maximum of 8 hours continuous log time.

### 4. Bluetooth® Setup & Wireless Communication

#### Initial Smartphone Pairing Process

1. Turn on your smartphone's Bluetooth and start the vehicle engine.
2. Confirm the Main Unit and Switch LEDs are solid.
3. Move the Mode Selection Slider to OFF.
4. Press and hold the START/STOP button for 3 seconds or longer.
5. Ensure the Switch LED and Status LED are blinking in unison.
6. On your smartphone's Bluetooth list, select the device named "GRRecorder".
7. Pairing is complete when the Switch LED remains solid and the Status LED shuts off.

## Frequently Asked Questions

- Q: Can I place items on top of the GNSS antenna?
  - A: No, keeping the antenna clear ensures correct vehicle positioning telemetry.
- Q: Can I use this if I have aftermarket wheels or tires?
  - A: Yes, provided the overall outer diameter of the tire matches the original specification.
- Q: Can I use this with a modified Engine ECU?
  - A: No, modified vehicles cannot be used with this system as telemetry data will be inaccurate.
- Q: What happens if I turn the car engine off while recording?
  - A: Data logged up to the exact moment the engine turns off is saved to the SD card.
- Q: Is there a log file limit?
  - A: There is no file count limit, but recording will fail if the card runs out of storage space.
- Q: Can I view or delete SD card files using the navigation screen?
  - A: No. Files cannot be played back or deleted on the nav system. Use a PC.

## Troubleshooting Guide

| Symptom | Probable Cause | Solution |
| --- | --- | --- |
| LEDs fail to light up. | Engine switch is turned OFF. | Turn the vehicle engine ON. |
| LEDs fail to light up. | Foreign debris covers the light. | Wipe off debris from the LED surface. |
| Data fails to record to SD. | Card is missing or loose. | Ensure the SD/SDHC card is pushed fully into place and the slot cover is shut tight. |
| Data fails to record to SD. | Formatting error. | Verify the card format is FAT16 or FAT32. |
| Data fails to record to SD. | Memory is full. | Free up space or transfer logs to a computer. |
| Data fails to record to SD. | Slider set to OFF. | Move the slider switch to either AUTO or MANU mode. |
| Data fails to record to SD. | GNSS signal missing. | Move vehicle to an open area away from tunnels or large structures. |
| Data fails to record to SD. | Battery was disconnected. | Satellite sync requires up to 3 minutes of uninterrupted idling to recalibrate. |
