# TOYOTA GAZOO Racing Viewer User Manual

## Vehicle Data Visualizer Works

### Screen Layout
The GR Viewer screen features function selection tabs on the far left edge. You can switch to the corresponding screen for each function by clicking these tabs.

#### Function Screen Configurations
- Data File Selection Screen: Select the Vehicle Data Visualizer (VDV) file and video files (up to 2 files) for playback.
- Project Open Screen: Open a previously saved project file.
- Course Selection Screen: Select the driving course for the VDV file.
- Lap Selection Screen: Select the specific driving lap you want to play back.
- Playback Screen: Synchronize and play back the contents of the VDV file alongside the video files.
- Project Save Screen: Save current selections—such as data files, course, and driving laps—as a named project file.

### How to Use
1. Launch GR Viewer to display the Data File Selection Screen.
2. Switch between VDV files, Video File ①, and Video File ② using the tabs on the far left of the file list.
3. First, select the VDV file recorded with the TOYOTA GAZOO Racing Recorder on this screen.
4. Next, select your video file. The video file chosen here must be recorded at the exact same time as the VDV file selected in Step 2. If you are not using video, skip to Step 5.
5. To display two videos simultaneously, select the second video file using the next tab.
6. Click the "OK" button located at the bottom right of the screen. The Course Selection Screen will appear.
7. The software automatically detects and selects the driving course from the VDV file data. If the detected course is incorrect, manually select the correct one. Click the "OK" button at the bottom right.
8. The Lap Selection Screen will appear. Select the specific lap you want to display in GR Viewer (or choose "ALL DATA"), then click the "OK" button at the bottom right.
9. The Playback Screen will display. Click the Play button to begin synchronized playback.
10. To save your current layout and data setup, switch to the Project Save Screen. Select your target destination folder, enter a project name, and click the "OK" button to save the project.
11. To load a previously saved project, navigate to the Project Open Screen, select your project file, and open it.
