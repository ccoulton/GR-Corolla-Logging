# GR Corolla optional CAN project

In an effort to be able to use the GR Race viewer accessory this is notes and files generated by chatgpt,and found though out the internet.

Race Recorder part number: 83960-52020
Interfaces with the Metra 71-1761 87-94

Ground ring terminal to frame.
Power tap: I197 Junction connector No. 40
Repair Crimp: 82998-24300 Crimp and black and orange
11 ECU-ACC
12 ECU-DCC

Bus: 500 kbit/s

Toyota GR Corolla/Toyota GR Yaris I174 (USDM) / H62 (JDM/EU)
1 CANL
2 CANH

Scion FR-s/Subaru BRZ/Toyota GR86 D29:
1 GND
2 B+  - ECU-DCC
3 NC
4 CAN-H
5 CAN-L
6 IGN - ECU-ACC

## Known mapped IDs

These identifiers were observed in `circuit python project/can_log.csv` and have a working signal label:

- `0x024` — G Force
- `0x025` — Steering
- `0x0AA` — Wheel Speeds
- `0x0D7` — Vehicle Speed
- `0x101` — Brake Pressure
- `0x115` — RPM
- `0x116` — Throttle
- `0x3C6` — Coolant
- `0x51E` — AWD Mode
